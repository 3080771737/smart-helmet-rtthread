⚡ 电源连接
VCC: 3.3V / 5V
GND: 公共地
🔵 I2C总线
PB6: I2C1_SCL
PB7: I2C1_SDA
🟢 UART串口
UART1: PA9(TX), PA10(RX)
UART2: PA2(TX), PA3(RX)
UART3: PB10(TX), PB11(RX)
🟠 ADC模拟输入
PA0: ADC1_IN0
16-bit, 3.3V参考
🟣 GPIO数字IO
PA8: DHT11 (Open-Drain)
PO5: LED指示灯

📝 接线注意事项

  • 电源: MPU6050、MAX30102、DHT11、ATGM336H、ESP-01S 使用3.3V供电,MQ2使用5V供电
  • I2C: MPU6050和MAX30102共享I2C1总线,注意上拉电阻(开发板已集成)
  • UART: 所有UART设备波特率需在代码中正确配置(UART1:115200, UART2:9600, UART3:115200)
  • ADC: MQ2输出0-5V模拟电压,需使用分压电路降至0-3.3V或使用5V容忍引脚
  • GPIO: DHT11使用Open-Drain模式,需要4.7kΩ上拉电阻
  • WiFi: ESP-01S需要稳定的电源,建议独立供电或增加滤波电容
✅ 测试建议: 建议按照 I2C设备 → ADC设备 → GPIO设备 → UART设备 的顺序逐个测试,确保每个模块单独工作正常后再集成。
