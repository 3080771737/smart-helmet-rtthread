🔧 RT-Thread线程架构

7个独立线程并发执行,优先级抢占式调度

线程名 优先级 栈大小 周期 功能描述
mpu6050 15 (高) 1024B 100ms MPU6050姿态传感器,跌倒/碰撞检测
max30102 16 (高) 1024B 200ms MAX30102心率血氧传感器
dht11 17 (中) 512B 1000ms DHT11温湿度传感器
mq2 17 (中) 512B 100ms MQ2气体浓度传感器
gps 18 (中) 1024B 1000ms ATGM336H GPS定位模块
wifi 19 (低) 2048B 1000ms ESP-01S WiFi数据上报
led 20 (低) 256B 500ms LED状态指示灯

RT-Thread API使用示例

main.c 
/* RT-Thread线程创建 */
mpu6050_thread = rt_thread_create("mpu6050",
                                  mpu6050_thread_entry,
                                  RT_NULL,
                                  1024,    /* 栈大小 */
                                  15,      /* 优先级 */
                                  10);     /* 时间片 */
rt_thread_startup(mpu6050_thread);

/* 互斥锁同步 */
sensor_mutex = rt_mutex_create("sen_lock", RT_IPC_FLAG_PRIO);
rt_mutex_take(sensor_mutex, RT_WAITING_FOREVER);
g_sensor_data.heart_rate = 72;  /* 安全访问共享数据 */
rt_mutex_release(sensor_mutex);

/* MSH命令行 */
static int sensor_read(int argc, char **argv) {
    rt_kprintf("心率: %d bpm\\n", g_sensor_data.heart_rate);
    return 0;
}
MSH_CMD_EXPORT(sensor_read, Read all sensor data);

/* 自动初始化 */
INIT_APP_EXPORT(sensor_threads_init);

🔌 硬件框架

STM32H7R7 + 7大传感器模块

主控平台

  • 主控MCU STM32H7R7VIT6
  • 内核 Cortex-M7 @ 600MHz
  • Flash 2MB + 64MB外部
  • RAM 640KB
  • 开发板 ART-Pi2 (正点原子)

传感器模块

  • MPU6050 I2C1 (PB6/PB7)
  • MAX30102 I2C2 (PF1/PF0)
  • MQ2 ADC1 (PA0)
  • DHT11 GPIO (PA8)
  • ATGM336H UART2 (PA2/PA3)
  • ESP-01S UART3 (PB10/PB11)

性能数据

  • 线程数量 7个
  • 内存使用 ~52KB / 640KB
  • 线程切换 <1us
  • 中断响应 <10us
  • 任务延迟 <1ms
  • 上报频率 1Hz
