## 🔌 传感器模块连接表

### 1. MPU6050 六轴姿态传感器

**接口类型**: I2C1 (硬件I2C)

| MPU6050引脚 | STM32引脚 | 功能说明 | 备注 |
|------------|----------|---------|------|
| **VCC** | **3.3V** | 电源正极 | 不能接5V,会烧毁芯片 |
| **GND** | **GND** | 电源地 | 公共地 |
| **SCL** | **PB6** | I2C1时钟线 | 需要4.7kΩ上拉电阻(开发板已集成) |
| **SDA** | **PB7** | I2C1数据线 | 需要4.7kΩ上拉电阻(开发板已集成) |
| AD0 | GND | I2C地址选择 | 接GND时地址为0x68 |
| INT | (未使用) | 中断输出 | 可选,用于数据就绪中断 |

**I2C参数**:
- **地址**: 0x68 (7位地址)
- **速度**: 400 kHz (快速模式)
- **电平**: 3.3V

**功能**:
- 三轴加速度计 (±2g/±4g/±8g/±16g可配置)
- 三轴陀螺仪 (±250°/s ~ ±2000°/s可配置)
- DMP姿态解算
- 跌倒检测算法

### 2. MAX30102 心率血氧传感器

**接口类型**: I2C2 (硬件I2C)

| MAX30102引脚 | STM32引脚 | 功能说明 | 备注 |
|-------------|----------|---------|------|
| **VCC** | **3.3V** | 电源正极 | 1.8V~3.3V供电 |
| **GND** | **GND** | 电源地 | 公共地 |
| **SCL** | **PF1** | I2C2时钟线 | I2C2_SCL |
| **SDA** | **PF0** | I2C2数据线 | I2C2_SDA |
| INT | PD13 (可选) | 中断输出 | 低电平有效,数据FIFO就绪 |

**I2C参数**:
- **地址**: 0x57 (7位地址: 0xAE>>1)
- **速度**: 400 kHz
- **电平**: 3.3V

**功能**:
- 红光LED (660 nm)
- 红外LED (880 nm)
- 心率监测 (50-100 BPM典型范围)
- 血氧饱和度 (SpO2: 90-100%)

**注意事项**:
- MAX30102需要稳定的3.3V供电,建议加100nF去耦电容
- 传感器需要紧密接触皮肤才能正常工作

### 3. MQ2 可燃气体传感器

**接口类型**: ADC1 (模拟输入)

| MQ2引脚 | STM32引脚 | 功能说明 | 备注 |
|---------|----------|---------|------|
| **VCC** | **5V** | 电源正极 | MQ2加热需要5V供电 |
| **GND** | **GND** | 电源地 | 公共地 |
| **A0** | **PA0** | 模拟输出 | ADC1_IN0通道 |
| D0 | (未使用) | 数字输出 | 可选,超过阈值输出高电平 |

**ADC参数**:

- **通道**: ADC1_IN0
- **分辨率**: 16位 (0-65535)
- **参考电压**: 3.3V
- **采样时间**: 640.5周期

**重要警告**:
⚠️ **MQ2输出0-5V,STM32引脚只能承受3.3V!**

**解决方案**:
1. **方案A (推荐)**: 使用电阻分压
   ```
   MQ2 A0 ----[ 20kΩ ]----+---- PA0 (STM32)
                           |
                      [ 33kΩ ]
                           |
                          GND
   
   分压比: Vout = 5V × (33kΩ / (20kΩ + 33kΩ)) = 3.11V ✓
   ```

2. **方案B**: 使用3.3V稳压输出给MQ2供电(会影响灵敏度)

3. **方案C**: 使用电平转换芯片(如TXS0108E)

**功能**:
- 检测可燃气体: LPG、甲烷、氢气等
- 浓度范围: 300-10000 ppm
- 预热时间: 24-48小时(首次使用)

### 4. DHT11 温湿度传感器

**接口类型**: GPIO (单总线协议)

| DHT11引脚 | STM32引脚 | 功能说明 | 备注 |
|-----------|----------|---------|------|
| **VCC** | **3.3V** | 电源正极 | 3.3V~5V供电 |
| **GND** | **GND** | 电源地 | 公共地 |
| **DATA** | **PA8** | 数据线 | 开漏输出,需要上拉电阻 |

**GPIO配置**:
- **模式**: 开漏输出 + 输入切换
- **上拉电阻**: 4.7kΩ (必须!)
- **速度**: 高速 (50MHz)

**外部电路**:
```
        +3.3V
          |
       4.7kΩ (上拉电阻,必须!)
          |
   DHT11 DATA ---- PA8 (STM32)
```

**通信协议**:
- 单总线协议,时序严格
- 数据位: 40位 (湿度16位 + 温度16位 + 校验8位)
- 采样间隔: ≥1秒

**功能**:
- 温度范围: 0-50°C (±2°C精度)
- 湿度范围: 20-90% RH (±5% 精度)

### 5. ATGM336H GPS定位模块

**接口类型**: UART2 (异步串口)

| ATGM336H引脚 | STM32引脚 | 功能说明 | 备注 |
|-------------|----------|---------|------|
| **VCC** | **3.3V** | 电源正极 | 3.3V~5V供电 |
| **GND** | **GND** | 电源地 | 公共地 |
| **TX** | **PA3** | 发送数据 | GPS发送 → STM32接收 (USART2_RX) |
| **RX** | **PA2** | 接收数据 | STM32发送 → GPS接收 (USART2_TX) |
| PPS | (未使用) | 秒脉冲输出 | 可选,GPS定位成功后输出1Hz方波 |

**UART参数**:
- **波特率**: 9600 bps
- **数据位**: 8位
- **停止位**: 1位
- **校验位**: 无
- **流控**: 无

**数据格式**:
- **协议**: NMEA-0183
- **常用语句**:
  - `$GPGGA`: 定位数据(时间、经纬度、海拔、卫星数)
  - `$GPRMC`: 推荐定位信息(速度、方向)
  - `$GPGSV`: 卫星信息

**功能**:
- 定位精度: 2.5m CEP (冷启动)
- 更新频率: 1 Hz (可配置到10 Hz)
- 支持GPS、北斗、GLONASS

**注意事项**:
- GPS需要室外天线或窗边才能搜星
- 冷启动可能需要1-3分钟

### 6. ESP-01S WiFi模块

**接口类型**: UART3 (异步串口)

| ESP-01S引脚 | STM32引脚 | 功能说明 | 备注 |
|------------|----------|---------|------|
| **VCC** | **3.3V** | 电源正极 | 3.3V供电,电流≥300mA! |
| **GND** | **GND** | 电源地 | 公共地 |
| **TX** | **PB11** | 发送数据 | ESP发送 → STM32接收 (USART3_RX) |
| **RX** | **PB10** | 接收数据 | STM32发送 → ESP接收 (USART3_TX) |
| CH_PD (EN) | 3.3V | 芯片使能 | 必须接高电平,否则无法工作 |
| RST | (可选) | 复位 | 低电平复位,可加按键或接GPIO |
| GPIO0 | 悬空 | 启动模式 | 正常运行时悬空或接高电平 |
| GPIO2 | 悬空 | 保留 | 正常运行时悬空 |

**UART参数**:
- **波特率**: 115200 bps (默认)
- **数据位**: 8位
- **停止位**: 1位
- **校验位**: 无
- **流控**: 无

**AT命令示例**:
```
AT              // 测试通信
AT+CWMODE=1     // 设置为Station模式
AT+CWJAP="SSID","PASSWORD"  // 连接WiFi
AT+CIPSTART="TCP","iot.huawei.com",1883  // 连接MQTT服务器
```

**⚠️ 重要警告**:
1. **电源要求严格**: ESP-01S峰值电流可达300mA,普通开发板3.3V引脚可能供电不足
   - **推荐**: 使用独立的AMS1117-3.3稳压模块
   - 加100μF电容在VCC和GND之间

2. **电平匹配**: ESP-01S是3.3V电平,与STM32完美兼容

**功能**:
- WiFi 802.11 b/g/n
- TCP/IP协议栈
- MQTT客户端
- 数据上报到华为云IoT平台

## 🔋 电源供电方案

### 方案A: USB供电 (调试阶段推荐)

```
USB 5V → ART-Pi2开发板
         ├─→ 3.3V稳压器 (AMS1117-3.3) → 3.3V总线
         │    ├─→ STM32H7R7 (3.3V IO)
         │    ├─→ MPU6050 (3.3V)
         │    ├─→ MAX30102 (3.3V)
         │    ├─→ DHT11 (3.3V)
         │    ├─→ ATGM336H (3.3V)
         │    └─→ ESP-01S (需独立稳压模块,300mA峰值电流)
         └─→ 5V总线
              ├─→ MQ2 (5V)
              └─→ ASRpro (5V)
```

### 方案B: 电池供电 (实际使用)

**电池选择**:
- **类型**: 18650锂电池 × 2节串联
- **电压**: 7.4V (标称) / 8.4V (充满)
- **容量**: ≥2000mAh

**电源管理**:
```
7.4V电池 → DC-DC降压模块
            ├─→ 5V输出 (1A) → 5V总线
            │    ├─→ 3.3V稳压器 → 3.3V总线
            │    ├─→ MQ2
            │    └─→ ASRpro
            └─→ 充电管理芯片 (TP4056)
```

**总功耗估算**:
| 模块 | 电压 | 电流 | 功耗 |
|------|------|------|------|
| STM32H7R7 | 3.3V | ~150mA | 0.5W |
| MPU6050 | 3.3V | 3.8mA | 0.01W |
| MAX30102 | 3.3V | ~50mA | 0.17W |
| DHT11 | 3.3V | ~1mA | 0.003W |
| MQ2 | 5V | ~150mA | 0.75W |
| ATGM336H | 3.3V | ~40mA | 0.13W |
| ESP-01S | 3.3V | ~80mA (平均) | 0.26W |
| **总计** | - | - | **~1.82W** |

**续航时间**:
- 电池容量: 2000mAh × 7.4V = 14.8Wh
- 理论续航: 14.8Wh / 1.82W ≈ **8.1小时**
- 实际续航: 约**6-7小时** (考虑转换效率)

## 📐 PCB布局建议

### 布局原则

1. **电源走线**:
   - 3.3V和5V电源线加粗(≥1mm)
   - GND敷铜(地平面)
   - 每个芯片VCC引脚旁边加0.1μF去耦电容

2. **信号完整性**:
   - I2C走线尽量短(<10cm)
   - UART可以适当长一些
   - 避免高速信号和模拟信号交叉

3. **模块位置**:
   ```
   [ESP-01S]             [GPS天线]
       |                     |
   [STM32核心板]         [ATGM336H]
       |
   [MPU6050] [MAX30102]
       |
   [DHT11]   [MQ2]
   ```

4. **干扰隔离**:
   - MQ2(加热元件)远离温度传感器
   - GPS模块远离ESP-01S(射频干扰)
   - 电源模块单独区域

## 🛠️ 接线实物示意图

**工具**: 杜邦线 + 面包板(原型阶段)

### I2C总线接线

```
MPU6050            STM32H7R7
  VCC  ────────────  3.3V
  GND  ────────────  GND
  SCL  ─────┬───────  PB6 (I2C1_SCL)
            │
  SDA  ─────┼───────  PB7 (I2C1_SDA)
            │
            │
MAX30102          STM32H7R7
  VCC  ────────────  3.3V
  GND  ────────────  GND
  SCL  ────────────  PF1 (I2C2_SCL)
  SDA  ────────────  PF0 (I2C2_SDA)
```

**上拉电阻**:
```
      +3.3V
        |
     4.7kΩ (I2C1_SCL上拉)
        |
       PB6

      +3.3V
        |
     4.7kΩ (I2C1_SDA上拉)
        |
       PB7
```

### UART接线(交叉连接)

```
GPS (ATGM336H)     STM32H7R7
    TX  ───────────→  PA3 (USART2_RX)
    RX  ←───────────  PA2 (USART2_TX)

ESP-01S            STM32H7R7
    TX  ───────────→  PB11 (USART3_RX)
    RX  ←───────────  PB10 (USART3_TX)
```

⚠️ **注意**: UART的TX接RX,RX接TX(交叉连接)!

## ✅ 接线检查清单

在上电前,请逐项检查:

- [ ] **电源电压正确**
  - [ ] MPU6050, MAX30102, DHT11, GPS, ESP-01S 接3.3V
  - [ ] MQ2, ASRpro 接5V
  - [ ] 没有模块误接反

- [ ] **I2C连接**
  - [ ] SCL和SDA没有接反
  - [ ] 上拉电阻已连接(4.7kΩ)
  - [ ] 两个设备使用不同的I2C总线(I2C1和I2C2)

- [ ] **UART连接**
  - [ ] TX接RX,RX接TX(交叉连接)
  - [ ] 波特率已在代码中配置正确

- [ ] **ADC保护**
  - [ ] MQ2输出已通过分压电路降至3.3V以下
  - [ ] 或使用了5V容忍引脚

- [ ] **上拉电阻**
  - [ ] DHT11数据线有4.7kΩ上拉
  - [ ] I2C总线有上拉电阻

- [ ] **ESP-01S特殊配置**
  - [ ] CH_PD(EN)引脚接3.3V
  - [ ] 电源独立稳压(300mA能力)
  - [ ] 100μF电容已连接

- [ ] **公共地**
  - [ ] 所有模块GND连接到一起
